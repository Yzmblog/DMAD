# ComfyUI-DMAD

Custom nodes for the DMAD 4-step students of MiniMax-H3: **DMAD Sampler (re-noise)** and **DMAD Sigmas**. ComfyUI's
stock `lcm` sampler with the `simple` scheduler gives bit-identical videos, so the nodes are optional. To install, copy
or symlink this folder into `ComfyUI/custom_nodes/`.

Usage, LoRA downloads and ready-to-run 24 GB workflows: [`comfyui/README.md`](../README.md).
